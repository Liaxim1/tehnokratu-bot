# Telegram World Review Bot

Бот щодня збирає актуальну картину світу через вебпошук OpenAI, готує авторський український огляд і публікує його у Telegram-каналі.

## Що вміє

- щоденна автоматична публікація у заданий час;
- `/post` — створити та опублікувати допис негайно;
- `/preview` — створити допис у приватному чаті з ботом без публікації;
- `/start` і `/help` — довідка;
- доступ до команд лише для `ADMIN_ID`;
- автоматичний поділ довгих дописів під ліміт Telegram;
- часовий пояс Europe/Kyiv за замовчуванням.

## Налаштування Telegram

1. Створіть бота через @BotFather і отримайте токен.
2. Додайте бота до вашого каналу як адміністратора з правом публікувати повідомлення.
3. Вкажіть username каналу у `TELEGRAM_CHANNEL_ID`, наприклад `@my_channel`.
4. Напишіть боту `/start` і подивіться свій числовий Telegram ID через надійний бот/інструмент. Вкажіть його у `ADMIN_ID`.

Telegram Bot API підтримує надсилання повідомлень у канали через `sendMessage`; бот має бути доданий до каналу з відповідними правами.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
# заповніть .env
python bot.py
```

Для постійної роботи бот має працювати на сервері/VPS або іншому постійно увімкненому середовищі.

## Важливо

Цей бот не читає ваші особисті чати ChatGPT. Він самостійно формує огляд через OpenAI Responses API та вебпошук. Це зроблено навмисно: так бот не залежить від того, чи відкритий ваш ChatGPT.
